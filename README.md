# PoPoDay V1.2

个人生活管理 PWA，适配手机浏览器与桌面端。

## 页面
- 首页：今日任务、成长进度、本周节奏
- 计划：按日/周/月查看，支持新增、编辑、删除任务
- 训练：工作日居家力量训练、B站跟练入口、周末健身房有氧记录
- 财务：按物品名称、金额、分类、日期记账，支持编辑和删除，并提供本月分类分析
- 我的：训练偏好、数据导入与导出

## 使用
将仓库部署到 GitHub Pages。手机 Safari 打开网站后，使用“分享 -> 添加到主屏幕”即可作为 PWA 使用。

## 数据说明
数据保存在当前浏览器 localStorage。升级时沿用原有 `popoday-v1` 存储键，保留已有支出、训练和自定义计划等记录；旧版本中的日记任务会从任务列表中排除。建议定期在“我的”中导出备份。
